## 系统架构

## 统一接口概述

### 核心组件

| 组件 | 文件 | 说明 |
|------|------|------|
| `BaseModelManager` | model_manager.py | 抽象基类，定义模型管理器接口 |
| `create_model_manager()` | model_manager.py | 工厂函数，根据类型创建模型管理器 |
| `postprocess_and_draw()` | model_manager.py | 统一后处理：过滤、绘制边界框 |
| `save_detection_results()` | model_manager.py | 统一保存检测结果到标签文件 |
| `run_inference_unified()` | model_manager.py | 统一推理函数（推理+后处理一步完成） |

### 支持的模型类型

| 类型 | 模型管理器 | 说明 |
|------|-----------|------|
| `yolo` | YOLOModelManager | YOLO 系列模型 |
| `large` | LargeVisionModelManager | 大视觉模型（如 Qwen） |
| `custom` | 用户自定义 | 通过继承 BaseModelManager 接入 |

## 输入输出格式

### 输入格式

模型管理器接收的图像输入有两种形式：

**1. 图像文件路径** (str)：
```python
image_path = "/path/to/image.jpg"
bboxes = model_manager.inference(image_path)
```

**2. 图像数据** (numpy.ndarray)：
```python
import cv2
img = cv2.imread("/path/to/image.jpg")
bboxes = model_manager.inference(img)
```

### 输出格式

所有模型管理器必须返回统一的边界框格式：

```python
bboxes = [
    [cx, cy, w, h],           # 仅有坐标
    [cx, cy, w, h, conf],     # 坐标 + 置信度
    [cx, cy, w, h, conf, cls], # 坐标 + 置信度 + 类别ID
]
```

**坐标系说明：**
- `cx, cy`：边界框中心点坐标，相对于图像宽高的归一化值 (0-1)
- `w, h`：边界框宽度和高度，相对于图像宽高的归一化值 (0-1)
- `conf`：置信度 (0-1)，可选
- `cls`：类别ID (整数)，可选

## 模型管理器基类

所有模型管理器必须继承 `BaseModelManager` 并实现以下方法：

```python
from abc import ABC, abstractmethod
from typing import List, Any

class BaseModelManager(ABC):
    """模型管理器抽象基类"""

    def __init__(self, model_path: str):
        """
        初始化模型管理器

        Args:
            model_path: 模型文件或文件夹路径
        """
        self.model_path = model_path
        self.model = None
        self.classnames = None  # 类别名称列表，如 ['person', 'car']

    @abstractmethod
    def load_model(self):
        """加载模型到内存"""
        pass

    @abstractmethod
    def inference(self, image: Any, **kwargs) -> List[List[float]]:
        """
        执行推理

        Args:
            image: 图像路径或图像数据
            **kwargs: 其他推理参数

        Returns:
            List of bounding boxes in format [[cx, cy, w, h, conf, cls], ...]
        """
        pass

    @abstractmethod
    def unload_model(self):
        """卸载模型，释放内存"""
        pass
```

### 可选属性

| 属性名 | 类型 | 说明 |
|--------|------|------|
| `classnames` | List[str] | 类别名称列表，如 `['person', 'car', 'dog']` |
| `img_size` | int | 模型输入尺寸（用于日志显示） |

### 步骤 2：在工厂函数中注册新模型

编辑 `detector_gui/model_manager.py`，找到 `create_model_manager()` 函数，添加新的模型类型分支：

```python
def create_model_manager(model_type: str, model_path: str, **kwargs) -> BaseModelManager:
    """
    工厂函数：创建模型管理器

    Args:
        model_type: 'yolo', 'large', 或 'custom'
        model_path: 模型文件或文件夹路径
        **kwargs: 其他参数

    Returns:
        BaseModelManager 实例
    """
    if model_type == 'yolo':
        return YOLOModelManager(
            model_path,
            img_size=kwargs.get('img_size', 1024),
            conf_thres=kwargs.get('conf_thres', 0.25),
            iou_thres=kwargs.get('iou_thres', 0.45),
            device=kwargs.get('device', 'cuda' if __import__('torch').cuda.is_available() else 'cpu')
        )
    elif model_type == 'large':
        return LargeVisionModelManager(
            model_path,
            prompt=kwargs.get('prompt'),
            min_pixels=kwargs.get('min_pixels', 64 * 32 * 32),
            max_pixels=kwargs.get('max_pixels', 9800 * 32 * 32)
        )
    elif model_type == 'custom':  # 新增：自定义模型
        from my_model_manager import MyModelManager
        return MyModelManager(
            model_path,
            conf_thres=kwargs.get('conf_thres', 0.25),
            iou_thres=kwargs.get('iou_thres', 0.45)
        )
    else:
        raise ValueError(f"不支持的模型类型: {model_type}")
```

### 步骤 3：在 app.py 中使用新模型

在 `app.py` 的推理代码中，使用统一的模型管理器：

```python
from detector_gui.model_manager import (
    create_model_manager,
    postprocess_and_draw,
    save_detection_results
)

# 创建模型管理器
model_manager = create_model_manager(
    'custom',  # 模型类型
    '/path/to/your/model.pt',  # 模型路径
    conf_thres=0.25,
    iou_thres=0.45
)

# 加载模型
model_manager.load_model()

try:
    # 执行推理
    bboxes = model_manager.inference('/path/to/image.jpg')

    # 使用统一后处理函数
    img = cv2.imread('/path/to/image.jpg')
    imgH, imgW = img.shape[:2]

    filtered_bboxes, plotted, det_count = postprocess_and_draw(
        bboxes, (imgH, imgW),
        classnames=model_manager.classnames,
        ignore_classes=[],  # 需要忽略的类别ID列表
        original_image=img
    )

    # 保存结果
    if filtered_bboxes:
        save_detection_results(
            filtered_bboxes, '/path/to/output.txt',
            classnames=model_manager.classnames,
            ignore_classes=[]
        )
finally:
    # 卸载模型
    model_manager.unload_model()
```

## 完整示例

以下是一个完整的目标检测模型接入示例（使用 OpenCV DNN）：

```python
# detector_gui/dnn_model_manager.py

import cv2
import numpy as np
from typing import List, Any
from detector_gui.model_manager import BaseModelManager

class DNNModelManager(BaseModelManager):
    """使用 OpenCV DNN 的目标检测模型管理器"""

    def __init__(self, model_path: str, config_path: str = None, **kwargs):
        """
        Args:
            model_path: 模型权重文件路径 (.pb, .onnx, .weights)
            config_path: 模型配置文件路径 (.pbtxt, .cfg, .onnx)
            **kwargs: 其他参数
        """
        super().__init__(model_path)
        self.config_path = config_path
        self.model = None
        self.conf_thres = kwargs.get('conf_thres', 0.5)
        self.classnames = ['person', 'bicycle', 'car', 'motorcycle',
                          'airplane', 'bus', 'train', 'truck', 'boat']
        self.img_size = kwargs.get('img_size', 416)

    def load_model(self):
        """加载 OpenCV DNN 模型"""
        if self.model_path.endswith('.onnx'):
            self.model = cv2.dnn.readNetFromONNX(self.model_path)
        elif self.model_path.endswith('.pb'):
            self.model = cv2.dnn.readNetFromTensorflow(self.model_path)
        else:
            self.model = cv2.dnn.readNet(self.model_path,
                                        self.config_path if self.config_path else '')

    def inference(self, image: Any, **kwargs) -> List[List[float]]:
        """执行推理"""
        if isinstance(image, str):
            img = cv2.imread(image)
        else:
            img = image

        if img is None:
            return []

        img_h, img_w = img.shape[:2]
        blob = cv2.dnn.blobFromImage(img, 1/255.0,
                                     (self.img_size, self.img_size))
        self.model.setInput(blob)
        outputs = self.model.forward(self.model.getUnconnectedOutLayersNames())

        bboxes = []
        for output in outputs:
            for detection in output:
                scores = detection[5:]
                class_id = np.argmax(scores)
                confidence = scores[class_id]

                if confidence > self.conf_thres:
                    # OpenCV DNN 通常输出归一化的 [cx, cy, w, h]
                    cx, cy, w, h = detection[:4]
                    bboxes.append([cx, cy, w, h, float(confidence), int(class_id)])

        return bboxes

    def unload_model(self):
        """卸载模型"""
        if self.model is not None:
            del self.model
        self.model = None
```

在 `model_manager.py` 中注册：

## 注意事项

1. **边界框格式**：确保返回的边界框是归一化的 YOLO 格式 (cx, cy, w, h, 0-1)

2. **内存管理**：务必在 `unload_model()` 中释放模型资源，特别是 GPU 内存

3. **类别名称**：设置 `self.classnames` 以便在结果中显示正确的类别名称

4. **错误处理**：在 `inference()` 中处理图像读取失败等情况，返回空列表

5. **线程安全**：如果模型不支持多线程，确保在 app.py 中正确使用锁机制
